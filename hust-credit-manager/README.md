# hust学分管家（2023-2026级全校版）

原生微信小程序（WXML + WXSS + JS），用于本地模拟华科 2023、2024、2025、2026 级本科生按模块自查学分完成情况。

当前覆盖：

- 2023、2024、2025、2026 四个年级
- 34 个学院（医科分册按目录归入“同济医学院”）
- 2026 级 166 个、2025 级 168 个、2024 级 173 个、2023 级 177 个，共 684 个专业方案
- 覆盖实验班、国际学生、强基计划、双学位和方向制专业
- 机械设计制造及其自动化、社会学保留手工精校数据和互斥规则

## 2. 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向 `D:\hust-credit-manager`。
3. 项目已配置 AppID `wx67be2a042d429772`。
4. 后端服务选择“不使用云服务”。
5. 点击“编译”，从首页选择学院和专业。

项目没有 npm 依赖，也不需要配置服务器域名。

## 3. 全校数据

学院、专业、模块最低学分和课程名称来自本科生院公开的 2023、2024、2025、2026 级培养方案。2023/2024 旧版方案采用兼容解析和独立分包。

- 机械大类学科分册
- 电气信息学科分册
- 理科分册
- 文科分册
- 土建环分册
- 医科分册

2025 级来源：[华中科技大学本科生院－2025版培养方案](https://ugs.hust.edu.cn/info/1146/7142.htm)。

每个专业在页面上带有来源页码，例如“机械分册 · P19”。课程库采用“课程目录 + 专业课程映射”的紧凑结构。2026 完整数据保留在主包，2025、2024、2023 级课程数据分别位于独立分包。课程记录包含总学时和开课学期。

首页顶部可选择“2026级”“2025级”“2024级”或“2023级”培养方案。各年级的学院、专业、学制、课程、年级选择、本地进度和云端记录彼此独立；切换培养方案后会重新选择学院。

切换培养方案前会弹出不可撤销确认：确认后清除所有年级的本地与云端进度并切换到目标年级；取消则保持当前年级和数据不变。

### 转专业课程衔接

同一培养方案年级内从一个专业切换到另一个专业时，新专业看板会自动检测共同课程：

- 按课程名称和学分匹配两个专业的共同课程。
- 显示可导入的课程数、学时和学分，并列出部分课程名称。
- 用户可选择“导入共同课程”或“暂不导入”。
- 导入时按原课程完成学时比例折算到新专业；新专业已有进度更高时保留原进度。
- 与新专业互斥规则冲突的课程不会自动导入，并会显示跳过数量。
- 原专业进度不会被删除，两个专业的数据仍分别保存。

2025 使用 `cohort2025`、2024 使用 `cohort2024`、2023 使用 `cohort2023` 独立分包；2026 完整数据和公共首页保留在主包。主包约 1.29MB，低于 1.5MB 限制。各分包内的看板、课程录入、学时折算、学业预警和云端同步功能保持一致。2023/2024 医科数据来自 OCR 转换后的 Word 文档，课程与总学分已接入。

2023 医科专业名称和学制已按 2023 级医科 PDF 目录校正；其中“预防医学专业（本硕博实验班）”使用 PDF 对应章节独立抽取的课程，学制为五年。

2024 级共 33 个学院入口。与 2025/2026 的 34 个入口相比，2024 方案将环境设计、数字媒体艺术等设计类专业归在建筑与城市规划学院，没有单独的“设计学院”入口；软件学院已正常识别。

2026 级的“素质教育选修”中另接入了《2026～2027学年度第一学期2026级普通本科生思政选择性必修课课表（20261016）》的 28 门课程。每门课程为 32 学时、2 学分，按“28 选 1”校验，最多选择 1 门；选中后可正常拖动学时并折算学分。

机械设计制造及其自动化和社会学使用手工精校的模块、课程和二选一规则；其余专业由程序从 PDF 中自动抽取。实验班、国际学生、方向制专业、本研贯通培养方案等复杂规则，请同时对照原 PDF。

## 4. 计算与校验逻辑

核心逻辑位于 `utils/credit.js`。

### 总进度

```text
单门课程已得学分 = 课程学分 × 已完成学时 ÷ 课程总学时
已修总学分 = 所有已选课程已得学分之和
总进度 = min(已修总学分 / 毕业总学分, 100%)
```

### 模块进度

```text
模块已修 = 该模块下所有已勾选课程学分之和
模块缺口 = max(模块最低学分 - 模块已修, 0)
```

社会学专业选修还会检查 `minCourses`：至少 24 学分且至少 12 门课程，两项都满足才算达标。

### 特殊规则

- `tagMinCredits`：某个标签的课程至少修够指定学分。
- `minCourseCount`：模块至少修够指定门数。
- `choiceGroup`：互斥课组最多选 1 门。
- `static`：需要学生自行对照培养方案核对的文字规则。

### 二选一冲突

保存时 `validateSelection()` 会检查互斥组。超过上限会阻止保存，并弹出：

```text
冲突：机器人学 和 数控技术 只能选其一
```

录入页会在保存前实时显示红色冲突提示。

### 秋季学业自查

预警页和看板会根据“当前已修总学分”模拟学校秋季学业规则，页面明确标注结果仅供个人自查，不构成学校学籍处理结论：

- 一年级新生不参与本次梳理。
- 二年级：已修学分低于总学分 `2/3` 为黄牌，低于 `1/2` 为红牌。
- 三年级及以上：已修学分低于总学分 `3/4` 为黄牌，低于 `2/3` 为红牌。
- 红牌警示，或累计两次黄牌警示，应转入专科学习，否则予以退学处理。

点击首页专业卡片后，会按该专业学制弹出可选年级：四年制只显示一至四年级，五年制显示一至五年级，八年制显示一至八年级。选择结果按专业保存。预警页保留“此前已获黄牌次数”，用于判断本次是否形成第二次黄牌。

默认年级按当前学年自动计算：在 2026～2027 学年，2026 级默认一年级，2025 级默认二年级。用户在当前学年手动选择的年级会保留，进入下一学年后重新按入学年份计算默认值。

### 学时与学期录入

- 每门课程显示总学时和开课学期。
- 勾选课程后默认按总学时计满学分，可拖动进度条、逐小时加减、直接输入、清零或一键修满。
- 录入页可以按“全部学期”或具体学期筛选课程。
- 学分按完成学时比例实时折算，模块进度、总进度和学业预警同步更新。

## 5. 本地存储

`utils/store.js` 使用 `wx.setStorageSync` / `wx.getStorageSync` 按专业保存“课程 ID → 已完成学时”记录。旧版的已选课程 ID 数组会自动迁移为“全部学时已修”的记录。刷新页面或重新进入小程序后，进度仍会保留。

所有专业首次打开均从 0 学分开始。清空或重置后，不会重新填充示例进度。

### 启动位置恢复

- 首次使用不默认选择学院，专业列表显示引导提示。
- 用户选择过专业后，会记录上次学院、专业和年级。
- 冷启动小程序时直接回到上次专业的学分看板，不需要重新选择。
- 手动点击“切换专业”时会停留在首页，并自动选中上次学院，便于改选其他专业。

### 分享入口

- 首页、学分看板、课程录入和学业自查预警页均支持发送给好友。
- 首页、学分看板、课程录入页和学业自查预警页均支持分享到朋友圈。
- 2023、2024、2025 级分享路径会保留在对应分包，接收者不会错误进入主包看板。
- 分享内容只携带页面和专业标识，不包含分享者的课程、学时或学习进度。

### 进度保护

- 勾选课程、调整学时后会立即自动保存，离开录入页时也会再次保存。
- 每次保存同时写入主存储和本地备用副本；主存储缺失时自动从备用副本读取。
- 录入页显示最后保存时间。
- “复制备份码”可以把当前专业的学时记录复制到剪贴板；“恢复备份”可从剪贴板恢复对应专业。
- 手动清空课程会同时清除主存储和备用副本，避免旧备份被错误恢复。
- 首页“重置全部数据”会清除所有专业的选课、学时、年级、黄牌次数、本地主备份和当前用户的云端记录；云端清理失败时会中止本地清除，避免旧云端数据再次恢复。
- 云端清理会自动重试 3 次，删除完成后再次查询确认集合已为空；重置期间会暂时禁止新的同步写入。只有云端验证通过后才清除本地数据。

本地存储只属于当前微信账号和当前设备。清理微信缓存、删除小程序、切换设备或切换微信账号都可能导致本地记录不可见，此时需要使用之前复制的备份码恢复。若需要无需手动备份的自动跨设备同步，必须接入后端或微信云开发数据库；手机号授权本身不能保存进度。

### 云开发自动同步

项目已配置云开发环境：

```text
credit-manager-prod-d7b9270117ab
```

使用前需要在云开发控制台创建集合：

```text
credit_progress
```

集合权限设为“仅创建者可读写”。云开发会自动使用当前微信用户的 OpenID，无需手机号授权或自建登录页面。

同步策略：

- 本地编辑后立即写本地，并在约 1.2 秒后异步上传云端。
- 进入看板、预警或录入页时比较本地与云端的最后修改时间，自动采用较新的记录。
- 如果本地更新，则上传本地；如果云端更新，则恢复到本地。
- 云端不可用时不影响本地自动保存和备份码恢复。

## 6. 自动抽取与校正说明

- PDF 模块表按“素质教育、学科基础、专业核心、专业选修、集中实践、个性化发展”等类别解析。
- 部分医学和国际学生方案存在两阶段培养、学时/学分列互换、英文表格、方向制组合等情况，数据中已做人工校正并保留“抽取校正说明”。
- 如某专业课程表仍有未覆盖的课程，录入页会出现“其他已修课程（模块补充录入）”，用于补录课程库未列出的已修学分。
- 自动抽取数据适合自查与展示，不作为学校正式学分认定凭证。
